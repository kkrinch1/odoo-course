hr_hospital

A structured hospital workflow module for Odoo: doctors, patients, visits, diagnoses, schedules, role-based access, and printable doctor reporting inside one coherent training addon.

Feature Set

Designed for a realistic training submission, not a toy example.

Doctors and Patients

Shared person model, validated contact data, age calculation, personal doctor links, and mentor or intern relationships.

Visits and Diagnoses

Visit states, planned versus actual dates, costs, recommendations, diagnosis approval flow, and operational actions.

Disease Classifier

Hierarchical diseases with ICD-10 support, danger level classification, symptoms, and regional applicability.

Doctor Report

A4 printable report with company information, visit history, patient table, colored status badges, and per-doctor page separation.

Security Model

Roles are implemented through groups, access rights, and record rules.

Patient

Can read only personal visits linked to the current user.

Intern

Can read and edit only visits assigned to the intern doctor profile.

Doctor

Can work with personal visits and visits assigned to linked intern doctors.

Manager / Administrator

Managers can read all visits. Administrators receive full access, including data deletion across the module.

Included Components

Everything needed for review, testing, and demonstration is bundled.

  • List, form, search, calendar, pivot, and kanban interfaces
